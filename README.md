# Rust-replication

## Objective

This project is a Rust replication to test the capabilities of JAX in decreasing computing time. just adding the @jax.jit decorator to the function to minimize increases performance from 26 to 40 times. The algorithm finds the loglikelihood minimum from 0.22 to 1.2 seconds.
